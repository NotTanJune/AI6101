## Findings considered and rejected

- Separate dashboard-only UI: rejected because the requested deliverable is a
  TUI that runs and controls the harness. Keep one pipeline callable from both
  the TUI and headless CLI.
- Keep OpenAI on Chat Completions: rejected because `gpt-6.1-sol` and
  `gpt-6-astra` have no tool calling there and `gpt-6-luna` allows it only at
  `reasoning_effort: none` (verified 2026-10-04).
- Keep Gemini on `generateContent`: rejected because Google marks it legacy
  since June 2026; the Interactions API is the default.
- Gemini streaming in the first agent version: deferred because the stream's
  completion event omits `steps`, which stateless replay needs verbatim.
